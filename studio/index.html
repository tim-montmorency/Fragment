    Réglages du fragment

    Attributs ajoutés aux balises de la page, par exemple data-theme="dark" pour daisyUI. lang="fr" est ajouté automatiquement, sauf si un autre lang est indiqué.

    Réglages GitHub

    L'enregistrement fait un commit dans le répertoire GitHub. Il faut un jeton « fine-grained » limité à ce répertoire, avec la permission Contents : Read and write. Le jeton reste dans ce navigateur seulement.

    Index de la galerie — fragments.json est mis à jour à chaque enregistrement. Après des ajouts ou suppressions faits à la main dans f/, il peut être recréé :

    Fragment enregistré

    GitHub Pages republie le site, habituellement en moins d'une minute. Penser à faire un git pull dans la copie locale.
