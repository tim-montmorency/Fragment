    Recherche sur npm (jsDelivr), ou adresse de n'importe quel site collée dans le champ. Les bibliothèques sont chargées dans l'ordre de la liste ; un clic sur l'une d'elles permet de la modifier.

      Attributs ajoutés aux balises de la page, par exemple data-theme="dark" pour daisyUI. lang="fr" est ajouté automatiquement, sauf si un autre lang est indiqué.

      Code caché : enregistré dans avant.css, apres.css, avant.js et apres.js, utilisé dans l'aperçu, la visionneuse et les intégrations, mais jamais affiché dans les onglets. Ordre : bibliothèques, puis avant.css, style.css, apres.css (apres.css l'emporte à spécificité égale) et avant.js, script.js, apres.js. Les const, let et function déclarés dans avant.js sont accessibles dans script.js, sauf en mode module (import) : passer alors par window.

      Formatage ponctuel : bouton Formater au-dessus du code, ou Maj + Alt + F, pour l'onglet affiché. Ce réglage est conservé dans ce navigateur et s'applique à tous les fragments.

      Réglages GitHub

      L'enregistrement fait un commit dans le répertoire GitHub. Il faut un jeton « fine-grained » limité à ce répertoire, avec la permission Contents : Read and write. Le jeton est conservé dans ce navigateur : pas besoin de le saisir à nouveau. Le site publié et une copie locale (Go Live) ont chacun leur propre mémoire.
