      Réglages GitHub

      L'enregistrement fait un commit dans le répertoire GitHub. Il faut un jeton « fine-grained » limité à ce répertoire, avec la permission Contents : Read and write. Le jeton est conservé dans ce navigateur : pas besoin de le saisir à nouveau. Le site publié et une copie locale (Go Live) ont chacun leur propre mémoire.
